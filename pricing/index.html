Sizing

What is a tag, really?

One tag is one value: a temperature, a pressure, a motor run status, a calculated total. If a screen shows the same value twice, that is still one tag. If you calculate efficiency from four readings, the calculated value is a fifth tag.

One compact machine20–100 tags
One production line100–1,000 tags
Small plant1,000–5,000 tags
Large or regulated plant5,000–60,000 tags
FAQ

Licensing questions, answered

The commercial questions we get before a quote. Ask your dealer for the numbers.

Why are prices not listed on the website?

Dicot sells through an authorised dealer network. Dealers quote in their local context, bundle installation and support, and handle taxes and purchase formalities. Send an enquiry with your tag count and the nearest dealer will respond.

What counts as a tag?

A tag is one data point the software reads, writes or calculates, such as a temperature, a motor status or a totaliser. Licences are sized by the number of tags you need in a project.

Are software updates included?

Vision C, Vision S and Vision Web include free software updates during the supported licence term. A perpetual Vision C licence does not include future updates.

Can I start small and upgrade?

Yes. Vision C can forward data to Vision Web, and Vision S licences can be extended by tags or editions. Upgrades are handled through the dealer who sold the original licence.

Do you offer development or evaluation licences?

Vision S has separate development, runtime, client-server and web-client editions so you can build before you deploy. Ask your dealer about evaluation options for your scope.

Is there a subscription for on-premise software?

Vision C is licensed for a fixed term or perpetual. Vision S is licensed by tags with separate development and runtime editions. Vision Web and VGraphic cloud are yearly subscriptions.
