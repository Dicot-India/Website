The key label states its colour. Choose the build with the same colour; the other build will not accept it. If you are unsure, send a photo of the key label to sales@dicot.tech before downloading a large file.

Before you install

  • Windows 7 or Windows 10, 4 GB RAM recommended (1 GB minimum).
  • PostgreSQL is needed for historical logging.
  • Mount the ISO, or write it to a DVD, then run the setup inside.
  • Keep your licence key and licence ID to hand.
